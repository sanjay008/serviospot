================================================================================
                        SERVIOSPOT - API TEST FLOW
================================================================================

All APIs from ServioSpot.postman_collection.json (74 requests, 70 paths),
which screen calls them, and what to tap.

--------------------------------------------------------------------------------
 0. HOW TO READ THE LOG (Metro terminal)
--------------------------------------------------------------------------------

  Every API prints two blocks:

    [API #12] → POST https://app.erpportaal.nl/api/serviospot/getLeads
    SEND { "token": "LqgmLo…HyRj" }

    [API #12] ← OK 200 https://app.erpportaal.nl/api/serviospot/getLeads (310 ms)
    REPLY { "status_code": 200, "status": true, "data": { ... } }

  ← OK     = call worked
  ✗ FAIL   = call failed (status code + backend message is shown)
  token and password are always hidden.


--------------------------------------------------------------------------------
 1. BEFORE YOU START
--------------------------------------------------------------------------------

  [ ] One VENDOR account     → vendor screens and leads
  [ ] One CUSTOMER account   → requests, proposals, reviews
  [ ] Vendor on GOLD or PLATINUM plan
        (leads, calendar, saved quotes, statistics are off on Free)
  [ ] Development build on the phone
        (savePushToken only runs when notifications are allowed)

 3. TEST ORDER (switch between the two accounts)
--------------------------------------------------------------------------------

  A customer request reaches the vendor as a lead, so follow this order:

  STEP 1  VENDOR    Register / Login → Select plan → Your services → Home
  STEP 2  VENDOR    Add dishes, edit page, settings (section 5)
  STEP 3  VENDOR    More → Sign out
            │
            ▼
  STEP 4  CUSTOMER  Register / Login
  STEP 5  CUSTOMER  Browse, search, save favorites
  STEP 6  CUSTOMER  Verify email + phone
  STEP 7  CUSTOMER  Send a quote request              → submitRequest
  STEP 8  CUSTOMER  Me → Sign out
            │
            ▼
  STEP 9  VENDOR    Login → Requests tab → open the lead      → getLead
  STEP 10 VENDOR    "Yes, I can do it" → Send a price         → saveProposal
  STEP 11 VENDOR    Ask a question → send a message           → sendMessage
  STEP 12 VENDOR    Sign out
            │
            ▼
  STEP 13 CUSTOMER  Login → Requests → request → proposal     → getProposal
  STEP 14 CUSTOMER  Continue with provider                    → continueWithProvider
  STEP 15 CUSTOMER  Save outcome → write review               → saveOutcome, saveReview
  STEP 16 CUSTOMER  Notifications, Terms, Privacy, Report, Export
  STEP 17 CUSTOMER  Sign out
            │
            ▼
  STEP 18 VENDOR    Login → More → Reviews → Post reply       → saveReviewResponse
            │
            ▼
  STEP 19 LAST      Me → Delete account (TEST ACCOUNT ONLY)   → deleteAccount

 7. WHEN A CALL FAILS
--------------------------------------------------------------------------------

  LOG SAYS                         MEANING                       FIX
  -------------------------------  ----------------------------  -------------------------------
  401 token is required            Guest (not logged in)         Log in with a real account
  404 on getLead / getProposal     Opened a dummy row (dummy-…)  Open a real item from the list
  ✗ FAIL NETWORK                   No internet or wrong URL      Check EXPO_PUBLIC_API_URL
  Screen says "Not on this plan"   Vendor is on Free plan        More → Your plan → Gold/Platinum
